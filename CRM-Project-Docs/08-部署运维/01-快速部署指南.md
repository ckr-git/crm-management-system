# CRM系统部署指南（Docker + Ubuntu）

> 📌 本文档提供基于Docker和Ubuntu的CRM系统部署方案，适用于开发、测试和生产环境

---

## 🎯 部署概述

**部署方案**：使用Docker容器化部署，基于Ubuntu操作系统

**部署优势**：
- ✅ 环境隔离，避免依赖冲突
- ✅ 一键部署，快速启动
- ✅ 跨平台，开发生产环境一致
- ✅ 便于扩展和迁移

**所需时间**：约20分钟

**技术要求**：
- Ubuntu 20.04+ 或 Windows/Mac（安装Docker Desktop）
- Docker 20.10+
- Docker Compose 2.0+
- 有基本命令行操作能力

## 📦 一、环境准备

### 1. 安装Docker（Ubuntu）

```bash
# 更新包索引
sudo apt update

# 安装必要的依赖
sudo apt install -y ca-certificates curl gnupg lsb-release

# 添加Docker官方GPG密钥
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 设置Docker仓库
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装Docker Engine
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker

# 将当前用户添加到docker组（避免每次使用sudo）
sudo usermod -aG docker $USER
newgrp docker

# 验证安装
docker --version  # 应显示 Docker version 24.x.x
docker compose version  # 应显示 Docker Compose version 2.x.x
```

### 2. 安装Docker（Windows/Mac）

**Windows**：
- 下载 Docker Desktop：https://www.docker.com/products/docker-desktop/
- 双击安装包，按提示安装
- 安装后重启电脑
- 打开Docker Desktop，等待启动完成

**Mac**：
- 下载 Docker Desktop for Mac：https://www.docker.com/products/docker-desktop/
- 拖动到Applications文件夹
- 打开Docker Desktop

**验证安装**：
```bash
docker --version
docker compose version
```

### 3. 安装Git（可选）
下载地址：https://git-scm.com/

```bash
# Ubuntu
sudo apt install -y git

# 验证
git --version
```

## 🚀 二、Docker一键部署（推荐）

### 1. 下载项目代码
```bash
# 克隆或下载项目
git clone <your-repo-url>
cd crm-system

# 或者解压代码包
unzip crm-system.zip
cd crm-system
```

### 2. 项目目录结构
```
crm-system/
├── backend/              # 后端代码
├── frontend/             # 前端代码
├── docker-compose.yml    # Docker编排文件
├── .env.example          # 环境变量模板
└── README.md
```

### 3. 配置环境变量
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量（可选，使用默认值也可以）
nano .env
```

`.env` 文件内容：
```env
# 应用配置
NODE_ENV=production
APP_PORT=3000

# 数据库配置
MYSQL_ROOT_PASSWORD=root_password_123
MYSQL_DATABASE=crm_system
MYSQL_USER=crm_user
MYSQL_PASSWORD=crm_password_123

# Redis配置
REDIS_PASSWORD=redis_password_123

# JWT配置
JWT_SECRET=your_jwt_secret_key_change_me_in_production
JWT_EXPIRES_IN=7d

# 前端配置
VITE_API_BASE_URL=http://localhost:3000/api
```

### 4. 创建 Docker Compose 配置
创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  # MySQL数据库
  mysql:
    image: mysql:8.0
    container_name: crm-mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE}
      MYSQL_USER: ${MYSQL_USER}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      TZ: Asia/Shanghai
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
      - ./backend/database/init.sql:/docker-entrypoint-initdb.d/init.sql
    command: --default-authentication-plugin=mysql_native_password --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    networks:
      - crm-network
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-u", "root", "-p${MYSQL_ROOT_PASSWORD}"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Redis缓存
  redis:
    image: redis:7-alpine
    container_name: crm-redis
    restart: always
    command: redis-server --requirepass ${REDIS_PASSWORD}
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    networks:
      - crm-network
    healthcheck:
      test: ["CMD", "redis-cli", "--raw", "incr", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  # 后端API服务
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: crm-backend
    restart: always
    environment:
      NODE_ENV: ${NODE_ENV}
      PORT: ${APP_PORT}
      DB_HOST: mysql
      DB_PORT: 3306
      DB_NAME: ${MYSQL_DATABASE}
      DB_USER: ${MYSQL_USER}
      DB_PASSWORD: ${MYSQL_PASSWORD}
      REDIS_HOST: redis
      REDIS_PORT: 6379
      REDIS_PASSWORD: ${REDIS_PASSWORD}
      JWT_SECRET: ${JWT_SECRET}
      JWT_EXPIRES_IN: ${JWT_EXPIRES_IN}
    ports:
      - "3000:3000"
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_healthy
    volumes:
      - ./backend/logs:/app/logs
      - ./backend/uploads:/app/uploads
    networks:
      - crm-network
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/api/health"]
      interval: 30s
      timeout: 10s
      retries: 3

  # 前端服务
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
      args:
        VITE_API_BASE_URL: ${VITE_API_BASE_URL}
    container_name: crm-frontend
    restart: always
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - crm-network

volumes:
  mysql-data:
  redis-data:

networks:
  crm-network:
    driver: bridge
```

### 5. 创建 Dockerfile

**后端 Dockerfile** (`backend/Dockerfile`)：
```dockerfile
# 使用Node.js 18作为基础镜像
FROM node:18-alpine

# 设置工作目录
WORKDIR /app

# 复制package.json和package-lock.json
COPY package*.json ./

# 安装依赖
RUN npm ci --only=production

# 复制源代码
COPY . .

# 暴露端口
EXPOSE 3000

# 启动应用
CMD ["node", "src/server.js"]
```

**前端 Dockerfile** (`frontend/Dockerfile`)：
```dockerfile
# 构建阶段
FROM node:18-alpine AS builder

WORKDIR /app

# 复制package.json
COPY package*.json ./

# 安装依赖
RUN npm ci

# 复制源代码
COPY . .

# 构建参数
ARG VITE_API_BASE_URL
ENV VITE_API_BASE_URL=$VITE_API_BASE_URL

# 构建前端
RUN npm run build

# 生产阶段
FROM nginx:alpine

# 复制构建产物
COPY --from=builder /app/dist /usr/share/nginx/html

# 复制Nginx配置
COPY nginx.conf /etc/nginx/conf.d/default.conf

# 暴露端口
EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

**Nginx配置** (`frontend/nginx.conf`)：
```nginx
server {
    listen 80;
    server_name localhost;
    
    root /usr/share/nginx/html;
    index index.html;

    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api/ {
        proxy_pass http://backend:3000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 静态资源缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
}
```

### 6. 一键启动所有服务
```bash

# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f
```

### 8. Docker常用命令
```bash
# 停止所有容器
docker compose stop

# 启动所有容器
docker compose start

# 重启所有容器
docker compose restart

# 停止并删除所有容器
```

## 🔧 五、常见问题

### 1. 后端启动失败："数据库连接失败"
**原因**：MySQL未启动或密码错误

**解决**：
```bash
# Windows: 检查MySQL服务是否启动
services.msc

# 检查.env文件中的数据库密码是否正确
```

### 2. 前端页面空白
**原因**：后端API未启动或跨域问题

**解决**：
- 确保后端服务运行在 http://localhost:3000
- 检查浏览器控制台是否有错误信息

### 3. 登录提示"Token无效"
**原因**：JWT密钥配置错误

**解决**：
- 检查后端 `.env` 文件中的 `JWT_SECRET` 是否配置
- 重启后端服务

### 4. npm install 失败
**原因**：网络问题或npm源慢

**解决**：
```bash
# 切换淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

## 🛠️ 七、生产环境部署（云服务器）

### 简易部署步骤

#### 1. 购买云服务器
- 推荐配置：2核4G，5M带宽
- 操作系统：Ubuntu 22.04 LTS
- 云服务商：阿里云/腾讯云/华为云

#### 2. 安装环境
```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装MySQL
sudo apt install mysql-server -y

# 安装Nginx
sudo apt install nginx -y

# 安装PM2
sudo npm install -g pm2
```

#### 3. 部署后端
```bash
# 上传代码到服务器
scp -r crm-backend user@your-server-ip:/var/www/

# 连接服务器
ssh user@your-server-ip

# 进入目录
cd /var/www/crm-backend

# 安装依赖
npm install --production

# 配置环境变量
cp .env.example .env
vim .env  # 修改为生产环境配置

# 初始化数据库
npm run db:migrate

# 使用PM2启动
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

#### 4. 部署前端
```bash
# 本地打包
cd crm-frontend
npm run build

# 上传到服务器
scp -r dist/* user@your-server-ip:/var/www/crm-frontend/

# 配置Nginx
sudo vim /etc/nginx/sites-available/crm

# 粘贴以下配置：
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/crm-frontend;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# 启用配置
sudo ln -s /etc/nginx/sites-available/crm /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

#### 5. 配置域名和HTTPS（可选）
```bash
# 安装Certbot
sudo apt install certbot python3-certbot-nginx -y

# 获取SSL证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

### 数据库备份
```bash
# 手动备份
mysqldump -u root -p crm_system > backup_$(date +%Y%m%d).sql

# 定时备份（每天凌晨2点）
crontab -e
# 添加：
0 2 * * * mysqldump -u root -pYourPassword crm_system > /backup/crm_$(date +\%Y\%m\%d).sql
```
