# 技术选型方案

> 📌 本文档详细说明CRM系统的技术选型及选型理由

---

## 🎯 技术选型原则

1. **成熟稳定** - 选择经过大量实践验证的成熟技术
2. **学习成本低** - 考虑团队技能栈，选择容易上手的技术
3. **社区活跃** - 选择社区活跃、文档丰富的技术
4. **性能优秀** - 满足系统性能需求
5. **可扩展性** - 支持后续功能扩展

## 💻 前端技术栈

### 1. 核心框架：Vue 3.4

#### ✅ 选择理由
- **Composition API**：更好的代码组织和逻辑复用
- **TypeScript支持**：更好的类型提示，减少错误
- **性能优秀**：虚拟DOM优化，响应式系统重构
- **生态成熟**：组件库丰富，第三方库完善
- **学习曲线平缓**：相比React，更容易上手

### 5. HTTP请求：Axios 1.6

#### ✅ 选择理由
- **功能完善**：请求/响应拦截器，超时设置
- **Promise支持**：async/await友好
- **错误处理**：统一的错误处理机制
- **取消请求**：支持取消重复请求

#### 🔧 Axios封装

```javascript
// 请求拦截器：添加Token
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：统一处理错误
axios.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // Token过期，跳转登录
      router.push('/login')
    }
    return Promise.reject(error)
  }
)
```

- **成熟稳定**：世界上最流行的开源数据库

- **事务支持**：ACID特性，数据一致性有保障
- **生态完善**：工具、监控、备份方案成熟

#### 🔄 替代方案对比

| 数据库 | 优点 | 缺点 | 评分 |

### 4. ORM框架：Sequelize 6.35

#### ✅ 选择理由
- **Node最流行的ORM**：生态成熟，文档完善
- **支持多数据库**：MySQL、PostgreSQL、SQLite等
- **Model定义**：面向对象操作数据库
- **事务支持**：保证数据一致性
- **Migration**：数据库版本管理

#### 💡 Model示例

```javascript
// models/Customer.js
const { Model, DataTypes } = require('sequelize')

class Customer extends Model {}

Customer.init({
  id: {
    type: DataTypes.INTEGER,
    primaryKey: true,
    autoIncrement: true
  },
  name: {
    type: DataTypes.STRING(50),
    allowNull: false,
    comment: '客户姓名'
  },
  phone: {
    type: DataTypes.STRING(11),
    allowNull: false,
    unique: true,
    comment: '手机号'
  },
  company: {
    type: DataTypes.STRING(100),
    allowNull: false,
    comment: '公司名称'
  },
  ownerId: {
    type: DataTypes.INTEGER,
    allowNull: false,
    comment: '负责人ID'
  }
}, { sequelize, modelName: 'customer' })
```

### 6. 身份认证：JWT (jsonwebtoken)

#### ✅ 选择理由
- **无状态**：服务器不需要存储Session
- **跨域友好**：适合前后端分离架构
- **可扩展**：Token中可以存储用户信息
- **安全性高**：签名防篡改

#### 🔐 JWT实现流程

```
1. 用户登录 → 验证账号密码
2. 生成Token → jwt.sign({ userId, role }, secret, { expiresIn: '2h' })
3. 返回Token → 前端存储到 localStorage
4. 后续请求 → Header携带 Authorization: Bearer <token>
5. 验证Token → jwt.verify(token, secret) 解析用户信息
6. Token过期 → 返回401，前端跳转登录页
```

```nginx

  listen 80;
  server_name crm.example.com;

  # 前端静态文件
  location / {
    root /var/www/crm/dist;
    try_files $uri $uri/ /index.html;

  # 后端API代理
  location /api/ {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}
```
