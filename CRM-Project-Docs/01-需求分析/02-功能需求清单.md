# 功能需求清单

> 📌 本文档将所有功能需求整理成清单形式，方便开发时勾选确认

---

## 📋 模块一：客户管理模块

### 1.1 客户信息管理

#### ✅ 功能1：添加客户
- [ ] 基本信息录入（姓名、电话、公司）
- [ ] 业务信息录入（来源、行业、阶段）
- [ ] 扩展信息录入（标签、预算、期望成交时间）
- [ ] 手机号唯一性校验
- [ ] 客户编号自动生成（C+年月日+4位流水号）
- [ ] 表单数据验证（必填项、格式校验）
- [ ] 移动端名片扫描识别（可选功能）

#### ✅ 功能2：客户列表
- [ ] 列表展示（编号、姓名、公司、电话、阶段、负责人、最后跟进时间）
- [ ] 分页功能（每页20/50/100条可选）
- [ ] 排序功能（按创建时间、最后跟进时间排序）
- [ ] 快捷筛选（全部/今日待跟进/本周重点/超期未跟进）
- [ ] 高级筛选（阶段、来源、行业、时间范围、标签）
- [ ] 搜索功能（姓名、公司、电话模糊搜索）
- [ ] 手机号脱敏显示（138****1234）
- [ ] 批量操作（批量转移、批量导出、批量打标签）

#### ✅ 功能3：客户详情
- [ ] 基本信息卡片展示
- [ ] 业务信息卡片展示
- [ ] 跟进记录时间轴展示
- [ ] 销售机会关联展示
- [ ] 附件文件列表（合同、报价单等）
- [ ] 编辑客户信息
- [ ] 转移客户
- [ ] 删除客户（软删除，可恢复）

#### ✅ 功能4：跟进记录
- [ ] 添加跟进记录（沟通方式、时间、内容、反馈）
- [ ] 设置下次跟进计划
- [ ] 设置跟进提醒
- [ ] 修改客户销售阶段
- [ ] 跟进记录时间轴展示
- [ ] 跟进记录编辑/删除
- [ ] 上传附件（照片、文件）

#### ✅ 功能5：客户转移
- [ ] 单个客户转移
- [ ] 批量客户转移
- [ ] 选择转移目标销售
- [ ] 填写转移原因
- [ ] 通知原负责人和新负责人
- [ ] 记录转移日志
- [ ] 保留历史跟进记录

#### ✅ 功能6：客户导入导出
- [ ] Excel模板下载
- [ ] Excel批量导入客户
- [ ] 导入数据校验（手机号格式、必填项）
- [ ] 导入结果反馈（成功数、失败数、错误原因）
- [ ] 导出客户列表（Excel格式）
- [ ] 导出字段自定义选择
- [ ] 导出数据水印（防泄露）

---

### 1.2 公海池管理

#### ✅ 功能1：公海池规则
- [ ] 超过30天未跟进自动进入公海池
- [ ] 离职员工客户自动进入公海池
- [ ] 手动放入公海池
- [ ] 管理员强制放入公海池
- [ ] 公海池客户保护期设置

#### ✅ 功能2：公海池列表
- [ ] 公海池客户列表展示
- [ ] 显示原负责人
- [ ] 显示进入公海池原因和时间
- [ ] 显示历史跟进记录数量
- [ ] 筛选和搜索功能
- [ ] 查看客户详情和历史记录

#### ✅ 功能3：领取客户
- [ ] 从公海池领取客户
- [ ] 领取数量限制（每月20个）
- [ ] 领取后7天内首次跟进要求
- [ ] 未跟进自动退回公海池
- [ ] 同一客户30天内不能重复领取
- [ ] 领取日志记录

- [ ] 阶段变更原因记录

### 2.2 销售漏斗可视化

- [ ] 不同颜色标识紧急程度（绿/黄/红）

- [ ] 设置提醒
- [ ] 上传附件（报价单、合同）

## 📊 功能优先级划分

### P0（核心功能，第一期必做）
1. ✅ 用户登录注册
2. ✅ 客户信息管理（增删改查）
3. ✅ 客户列表筛选搜索
4. ✅ 跟进记录管理
5. ✅ 销售阶段管理
6. ✅ 基本权限控制（角色和数据权限）

### P1（重要功能，第一期尽量完成）
1. ✅ 客户转移
2. ✅ 公海池管理
3. ✅ 销售漏斗看板
4. ✅ 个人业绩统计
5. ✅ 团队业绩统计
6. ✅ 操作日志

### P2（增强功能，第二期完成）
1. ✅ 客户导入导出
2. ✅ 销售机会管理
3. ✅ 漏斗图分析
4. ✅ 客户来源分析
5. ✅ 报表导出
6. ✅ 组织架构管理

### P3（可选功能，根据需求决定）
1. ✅ 移动端名片扫描
2. ✅ 附件管理
3. ✅ 数据备份恢复
4. ✅ 定时报表推送
5. ✅ 客户价值分析
