# CRM系统测试计划

> 📌 本文档规划CRM系统的测试策略、测试用例和验收标准

---

## 📋 测试概述

### 测试目标
- 确保所有功能正确实现，无重大Bug
- 验证系统性能满足要求
- 确保用户体验流畅
- 保证数据安全和完整性

### 测试范围
- 功能测试（所有P0、P1功能）
- 界面测试（UI/UX）
- 兼容性测试（浏览器、屏幕分辨率）
- 性能测试（响应时间、并发）
- 安全测试（权限、数据安全）

### 测试环境
- **浏览器**：Chrome 最新版、Edge 最新版、Firefox 最新版
- **分辨率**：1920x1080、1366x768
- **服务器**：测试服务器（2核4G）
- **数据库**：MySQL 8.0（测试数据库）

| 接口 | 响应时间 | 要求 |
|------|---------|------|

| 客户详情查询 | ≤ 300ms | ✅ |

## 🔒 安全测试

### 安全测试清单
- [ ] 密码加密存储（BCrypt）
- [ ] Token验证正确
- [ ] Token过期自动跳转登录
- [ ] SQL注入防护（使用ORM参数化）
- [ ] XSS攻击防护（输入过滤）
- [ ] CSRF防护
- [ ] 敏感信息脱敏（手机号、邮箱）
- [ ] 权限验证正确（前后端都验证）
- [ ] 文件上传类型限制
- [ ] 操作日志记录完整
