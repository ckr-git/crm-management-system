> 📌 本文档详细设计客户管理模块的所有功能，包括界面原型、交互流程、数据处理

---

## 📋 模块概述

**模块名称**：客户管理模块

**功能范围**：
- 客户信息的增删改查
- 客户跟进记录管理
- 客户转移和分配
- 公海池管理
- 客户导入导出

**用户角色**：
- 销售人员（主要使用者）
- 销售经理（管理和分配）
- 系统管理员（配置和维护）

### 交互设计

**搜索功能**：
1. 输入关键词，支持搜索：客户姓名、公司名称、手机号
2. 实时防抖搜索（输入停止300ms后自动搜索）
3. 高级筛选：销售阶段、客户来源、所属行业、创建时间
4. 支持组合筛选

**快捷筛选标签**：
- 点击标签自动应用筛选条件
- 显示每个标签的数量
- 超期未跟进标签红色高亮

**列表展示**：
- 默认按"最后跟进时间"倒序排列
- 支持点击表头排序
- 手机号中间4位脱敏显示
- 销售阶段用不同颜色标签区分

**批量操作**：
- 勾选多个客户
- 批量转移给其他销售
- 批量打标签
- 批量导出

**业务逻辑**：
```javascript
// services/customerService.js
async getList(params) {
  const { page, pageSize, keyword, stage, quickFilter, userId, userRole } = params
  
  const where = {}
  
  // 数据权限
  if (userRole === 'salesperson') {
    where.owner_id = userId
  }
  
  // 关键词搜索
  if (keyword) {
    where[Op.or] = [
      { name: { [Op.like]: `%${keyword}%` } },
      { company: { [Op.like]: `%${keyword}%` } },
      { phone: { [Op.like]: `%${keyword}%` } }
    ]
  }
  
  // 销售阶段筛选
  if (stage) {
    where.stage = stage
  }
  
  // 快捷筛选
  if (quickFilter === 'today') {
    // 今日待跟进：next_followup_at 是今天
    where[Op.and] = [
      sequelize.where(
        sequelize.fn('DATE', sequelize.col('next_followup_at')),
        sequelize.fn('DATE', new Date())
      )
    ]
  } else if (quickFilter === 'overdue') {
    // 超期未跟进：超过30天未跟进
    const thirtyDaysAgo = new Date()
    thirtyDaysAgo.setDate(thirtyDaysAgo.getDate() - 30)
    where.last_followup_at = { [Op.lt]: thirtyDaysAgo }
  }
  
  const { count, rows } = await Customer.findAndCountAll({
    where,
    include: [{ model: User, as: 'owner', attributes: ['id', 'name'] }],
    limit: pageSize,
    offset: (page - 1) * pageSize,
    order: [['last_followup_at', 'DESC']]
  })
  
  return { list: rows, total: count, page, pageSize }
}
```


### 业务逻辑

**创建客户**：
1. 前端表单验证
2. 调用创建API
3. 后端验证手机号唯一性
4. 生成客户编号（C+年月日+4位流水号）
5. 保存到数据库
6. 返回成功，刷新列表

**编辑客户**：
1. 加载客户详情数据回填表单
2. 修改后提交
3. 手机号如有变更，验证唯一性
4. 更新数据库
5. 返回成功，刷新详情页

## 🎯 功能6：公海池

### 公海池列表

```
┌────────────────────────────────────────────────────────────────┐
│  客户管理 > 公海池                        本月已领取：5/20个     │
├────────────────────────────────────────────────────────────────┤
│  进入原因：[全部▼] [搜索]                                       │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 姓名 | 公司 | 原负责人 | 进入原因 | 进入时间 | 操作      │  │
│  ├──────────────────────────────────────────────────────────┤  │
│  │ 李四 | YY贸易 | 小刘 | 30天未跟进 | 15天前 | [领取]     │  │
│  │ 王五 | ZZ制造 | 已离职 | 员工离职 | 10天前 | [领取]     │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                  │
│  领取规则说明：                                                  │
│  • 每人每月最多领取20个客户                                     │
│  • 领取后7天内必须首次跟进，否则退回公海池                      │
│  • 同一客户30天内不能重复领取                                   │
└────────────────────────────────────────────────────────────────┘
```

### 业务逻辑

**自动进入公海池**：
- 定时任务（每天凌晨1点执行）
- 查询超过30天未跟进的客户
- 标记 `in_pool = 1`
- 记录进入公海池日志

**手动放入公海池**：
- 销售人员/经理主动放入
- 填写放入原因
- 更新客户状态

**领取客户**：
1. 检查本月领取数量是否超限
2. 更新客户的 `owner_id` 为当前用户
3. 标记 `in_pool = 0`
4. 记录领取时间
5. 创建7天内首次跟进提醒

**退回公海池**：
- 领取后7天未跟进，自动退回
- 定时任务检查并执行
